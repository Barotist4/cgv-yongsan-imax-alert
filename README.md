# CGV 용산아이파크몰 IMAX 텔레그램 알리미

`스파이더맨-브랜드 뉴 데이`와 `오디세이`의 용산아이파크몰 IMAX 공개 일정을
날짜 제한 없이 계속 확인합니다. 두 영화의 실제 IMAX 상영시간이 새로 감지되거나,
용산 IMAX의 새로운 예매 날짜가 활성화되면 텔레그램 메시지를 한 번만 보냅니다.

## IMAX 날짜 오픈 기록

용산 IMAX에서 새로운 예매 날짜가 활성화되면 `state.json`의
`imaxDateOpenings`에 날짜별 최초 발견 시각을 UTC와 한국 시각으로 저장합니다.
이 기록은 영화와 관계없는 IMAX 편성 오픈 경향을 나중에 비교하는 용도이며,
새 날짜가 활성화되면 텔레그램 알림도 보냅니다.

## 온라인 실행에 필요한 비밀값

GitHub 저장소의 `Settings → Secrets and variables → Actions`에서 아래 값을 등록합니다.

- `TELEGRAM_BOT_TOKEN`: BotFather가 발급한 토큰
- `TELEGRAM_CHAT_ID`: 선택 사항. 생략하면 봇에 보낸 `/start` 메시지에서 자동 확인합니다.

토큰을 파일이나 저장소에 직접 입력하지 마세요.

## 주의

CGV 화면 구조가 변경되거나 자동 접속을 제한하면 감지가 중단될 수 있습니다.
GitHub 예약 실행은 혼잡할 때 정확히 5분 간격으로 시작되지 않을 수 있습니다.
